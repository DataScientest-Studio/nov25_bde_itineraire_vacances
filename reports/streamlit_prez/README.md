# Streamlit Présentation - TripMango

Application Streamlit pour la présentation du projet TripMango - système de recommandation d'itinéraires de vacances.

## Lancement

```bash
cd reports/streamlit_prez
streamlit run main.py
```

## Structure

- **main.py** : Point d'entrée avec navigation multi-pages
- **pages/** : Ensemble des pages de la présentation
- **media/** : Images et ressources visuelles
